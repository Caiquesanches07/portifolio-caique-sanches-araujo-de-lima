# 🤖 AT5 — Síndrome do Progresso Forçado

## 📝 Descrição do Projeto

Este projeto apresenta o tema **Síndrome do Progresso Forçado**, com foco no impacto da vigilância algorítmica no trabalho remoto. O site organiza o conteúdo em páginas informativas sobre introdução, causas, sintomas, orientações e dados.

A interface possui navegação baseada no Bootstrap, gráfico de barras construído com Chart.js e um controle de alternância entre tema claro e escuro. A preferência de tema é salva no armazenamento local do navegador (`localStorage`).

## 🚀 Tecnologias Utilizadas

- **Estrutura:** HTML5.
- **Estilização:** CSS3.
- **Framework:** Bootstrap 5.3.3.
- **Gráficos:** Chart.js.
- **JavaScript:** alternância e persistência da preferência de tema.
- **Inteligência Artificial:** Gemini, utilizado como ferramenta de apoio no desenvolvimento front-end.

## 📊 Resultados e Aprendizados

- Organização de conteúdo em páginas temáticas.
- Construção de uma navegação responsiva com Bootstrap.
- Apresentação de dados em um gráfico de barras com Chart.js.
- Manipulação de classes CSS com JavaScript.
- Uso de `localStorage` para preservar a preferência de tema entre visitas.

## 🗂️ Estrutura do Projeto

- `index.html` — página inicial.
- `dados.html` — gráfico sobre o impacto da vigilância algorítmica.
- `pages/introducao.html` — introdução.
- `pages/causas.html` — causas.
- `pages/sintomas.html` — sintomas.
- `pages/diagnostico.html` — orientações.
- `css/trabalho.css` — estilos.
- `js/trabalho.js` — alternância de tema.
