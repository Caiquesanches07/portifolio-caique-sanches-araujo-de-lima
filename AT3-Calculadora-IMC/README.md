# 🧮 AT3 — Calculadora de IMC

## 📝 Descrição do Projeto

Este projeto consiste em uma calculadora de Índice de Massa Corporal (IMC). A pessoa informa o peso em quilogramas e a altura em metros; ao selecionar o botão **Calcular**, o JavaScript calcula o IMC pela fórmula:

`IMC = peso / (altura × altura)`

O resultado é exibido na página junto de uma classificação. O código também verifica se o peso e a altura foram informados e se a altura é válida.

> Este é um exercício acadêmico de programação. O resultado não substitui avaliação ou orientação de um profissional de saúde.

## 🚀 Tecnologias Utilizadas

- **Linguagem de marcação:** HTML5.
- **Estilização:** CSS3.
- **Lógica e cálculo:** JavaScript.

## 📊 Resultados e Aprendizados

- Captura de valores digitados em campos de formulário.
- Conversão e validação de dados numéricos.
- Uso de operadores matemáticos e estruturas condicionais.
- Atualização dinâmica do conteúdo HTML com JavaScript.
- Separação entre estrutura, estilo e comportamento da página.

## 🗂️ Arquivos do Projeto

- `index.html` — estrutura da calculadora e campos de entrada.
- `js/script.js` — função de cálculo e classificação do IMC.
