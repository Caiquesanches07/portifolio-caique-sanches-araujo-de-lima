# 🎮 AT4 — Fase Extra: História dos Videogames

## 📝 Descrição do Projeto

O **Fase Extra** é um site sobre a história dos videogames, apresentando uma jornada desde os primeiros consoles até a cultura atual dos jogos. O conteúdo é organizado em páginas de início, sobre, galeria, dados e curiosidades e contato.

A página inicial apresenta a proposta do site e direciona a pessoa visitante para as demais seções. O projeto utiliza uma identidade visual própria e componentes do Bootstrap para estruturar a navegação e o layout.

## 🚀 Tecnologias Utilizadas

- **Estrutura:** HTML5.
- **Estilização:** CSS3.
- **Framework:** Bootstrap 5.3.3.
- **Recursos visuais:** fontes externas e imagens/ilustrações do projeto.

## 📊 Resultados e Aprendizados

- Organização de um site com múltiplas páginas interligadas.
- Construção de navegação responsiva com componentes do Bootstrap.
- Aplicação de estilos personalizados sobre o framework.
- Organização de conteúdo histórico em seções temáticas.
- Prática de estruturação e apresentação de informações em uma interface web.

## 🗂️ Páginas do Projeto

- `index.html` — início.
- `sobre.html` — apresentação do tema.
- `galeria.html` — galeria de jogos e elementos relacionados.
- `dados.html` — dados e curiosidades.
- `contato.html` — contato.
